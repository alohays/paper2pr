# The deck genres, one per line. Single source of truth.
#
# A directory under Quarto/ is eligible for publishing only if it is listed
# here, so a stray folder cannot ship a deck by accident. Within an eligible
# genre, `publish: false` in a deck's .deck.yml excludes only that deck from
# Paper2PR Pages; direct rendering still works. scripts/deckpath.py and
# .github/workflows/deploy.yml both read this file; /new-deck validates
# against it. Adding a genre means adding a line here and a profile in
# .claude/rules/slide-profiles/ that names it: the profile declares
# `genre_default: <genre>`, and deckprofile.py reads the genre-to-profile
# mapping from the profiles themselves, so those two edits are the whole job.
# scripts/test_profiles.py fails when a genre here has no profile claiming it.
